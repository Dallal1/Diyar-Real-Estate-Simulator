# Diyar — تنظيم ملفات المشروع

تم تجهيز المجلدات داخل `Assets/_Diyar` في مشروع Unity الحالي.
إصدار المشروع عند الإضافة: `2022.3.42f1`.

## أين أضع الملفات؟

| المجلد داخل `_Diyar` | الاستخدام |
| --- | --- |
| `common/Scripts` | السكربتات المشتركة بين أجزاء اللعبة. |
| `common/Prefabs` | العناصر المشتركة القابلة لإعادة الاستخدام. |
| `common/UI` | الخطوط والأيقونات وملفات واجهة اللعبة. |
| `common/Art/Models` | المجسّمات ثلاثية الأبعاد. |
| `common/Art/Materials` | مواد الأسطح. |
| `common/Art/Textures` | صور الحجر والخشب وغيرها. |
| `common/Animations` | الأنيميشن وAnimator Controllers. |
| `common/Audio` | الأصوات والموسيقى. |
| `game/Scripts` | السكربتات الخاصة باللعب. |
| `game/Scenes` | مشاهد اللعب الجديدة. |
| `game/Prefabs` | العناصر الخاصة باللعب. |

الشرح بالعربية ونصوص واجهة اللعبة بالألمانية، مثل `Spielen` و`Beenden`.
ملفات `.gitkeep` تحفظ المجلدات الفارغة في Git ولا تضيف سلوكًا للعبة.
يحفظ Unity بيانات الملفات في `.meta`؛ احتفظ بها مع ملفات المشروع في Git.

## الملفات المهمة

- `.gitignore` في جذر المستودع الخارجي: قواعد استبعاد الملفات المؤقتة والمخرجات التي حددها المستخدم.
- `Assets/_Diyar/AGENTS.md`: تعليمات التعاون مع Codex الخاصة بملفات اللعبة.
- ملفات C# داخل `Scripts`: منطق اللعبة عند تنفيذه في الخطوات التالية.
- ملفات `.unity`: ترتيب المشهد؛ تُفتح وتُعدّل داخل Unity.
- ملفات Prefab وMaterial وAnimation: تُعدّل داخل Unity حسب العنصر المطلوب.

## التشغيل والإيقاف

1. افتح مجلد مشروع Unity الداخلي من Unity Hub.
2. افتح المشهد الموجود `Assets/Scenes/SampleScene.unity`.
3. اضغط `Play` لتشغيل المشهد داخل Unity، واضغطه مرة ثانية للإيقاف.

لا تحتاج هذه الخطوة إلى Build أو أوامر Terminal. إنشاء نسخة مستقلة يحتاج إلى Build؛ نسخة المتصفح تحتاج إعداد WebGL عند العمل على تلك المرحلة.

## التحقق داخل Unity

انتظر ظهور `Assets/_Diyar/common` و`Assets/_Diyar/game` في نافذة `Project`، ثم تأكد من عدم ظهور أخطاء جديدة في `Console`.
تمت إضافة المجلدات وملف الاستبعاد فقط، ولم تُضف سكربتات لعب أو حزم جديدة. لم تُختبر هذه الإضافة داخل Unity بعد.
